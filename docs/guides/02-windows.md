# Windows: cài đặt và cập nhật

Mỗi bản phát hành có hai tệp Windows trên trang https://github.com/Fedya3012/my-hub/releases/latest

| Tệp | Dùng khi | Cập nhật |
|---|---|---|
| `MyHub-x.y.z.w-x64-Setup.exe` | Dùng hằng ngày (nên chọn) | Tự tải bản mới ở nền, hỏi **Khởi động lại ngay** / **Để sau** |
| `MyHub-x.y.z.w-portable.exe` | Chạy không cần cài, ví dụ từ USB | Không tự cập nhật: chỉ báo **Có phiên bản mới**, bấm **Mở trang tải** để tải tay |

## Cài bản Setup

1. Tải `MyHub-…-x64-Setup.exe` rồi chạy.
2. Windows SmartScreen có thể báo **"Windows protected your PC"** vì app chưa có chứng chỉ ký số: bấm **More info → Run anyway**.
3. App mở ra, dữ liệu nằm trên máy này.

## Cập nhật

- Bản Setup tự kiểm tra GitHub mỗi lần mở. Tải xong thì hỏi khởi động lại; chọn **Để sau** thì bản mới được cài khi bạn đóng app.
- Muốn kiểm tra ngay: **Quản lý ứng dụng → Kiểm tra cập nhật**, rồi **Cập nhật**.
- Nếu hiện **"Không tự cập nhật được"**: bấm **Mở trang tải** và cài đè bản Setup mới, dữ liệu giữ nguyên.

## Vì sao nên dùng app Windows thay vì trình duyệt

App Windows có đủ codec nhạc (AAC, FLAC, Opus…), đọc thẳng thư mục nhạc và sách trên ổ cứng mà không sao chép, và tự cập nhật.
